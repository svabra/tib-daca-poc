# BIT DiDaCa modern mockup deck

This self-contained HTML deck contains five comparable design directions. Every direction uses
the same synthetic ESTV product scenario and contains explanatory copy, an editable metadata form,
a REST/PostgreSQL endpoint and schema table, plus code-native lineage and provenance graphics.

Start a local server from the repository root:

```powershell
python -m http.server 4173
```

Then open the concepts at a `1600 × 900` browser viewport:

- Swiss Grid Workspace: <http://127.0.0.1:4173/docs/mockups/modern/index.html?view=grid>
- Alpine Control Canvas: <http://127.0.0.1:4173/docs/mockups/modern/index.html?view=canvas>
- Federal Evidence Dossier: <http://127.0.0.1:4173/docs/mockups/modern/index.html?view=dossier>
- Glass Observatory: <http://127.0.0.1:4173/docs/mockups/modern/index.html?view=glass>
- Red Glass Federal Workspace: <http://127.0.0.1:4173/docs/mockups/modern/index.html?view=redglass>

There are no external dependencies or network assets. The Confederation mark is loaded from the
repository's shared design-system asset folder.
